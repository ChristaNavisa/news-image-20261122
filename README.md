# THE WORLD TODAY — Sunday 22 November 2026

One page of world news: 39 dated stories from Sunday 22 November 2026,
drawn as a classic broadsheet — serif masthead, three illustrated leads
with bodies, sources and certainty tags, fifteen illustrated cards, a
numbered world map, an ALSO ON list and a date check.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.png` (1024×1024, under 1 MiB). Python 3.13, standard
library only — no Pillow, no network. Two runs write identical bytes.
